# Musapur High School Portal

A bilingual Bangla and English school portal for Musapur High School, Noakhali.

## Local development

Install Node.js 20 or newer, then run:

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Project areas

- `src/app/page.tsx`: public home page and typed starter content
- `src/app/globals.css`: visual system and responsive styles
- `src/app/layout.tsx`: metadata and root layout
- `public/`: school logo and campus media can be added here

The notice and result collections are intentionally local starter data so they can later be replaced with Firebase or a Node API without changing the page structure.
